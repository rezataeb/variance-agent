# 75-second demo script

**0–10 sec — Problem**  
Finance teams can see that a number changed, but explaining why means reconciling summaries, scanning transactions, and checking whether the story is actually supported.

**10–22 sec — Product**  
Variance is an explain-the-change agent. I load July and August summaries plus 390 transactions, then run one analysis.

**22–43 sec — Result**  
Revenue increased 18.2%, led by Enterprise. The agent ranks customer-level drivers, quantifies concentration, identifies six churn events, and shows that gross margin improved by 2.2 points.

**43–58 sec — Better than a quick human review**  
It also finds a hidden reliability issue: most matched customers changed region labels, so the apparent regional outlier is not decision-grade. Instead of inventing causation, it tells finance what additional data is needed.

**58–70 sec — Trust**  
Every summary reconciles to transaction detail. Each run is recorded in PRISM so I can observe failures, improve the guardrail, and prove the output changed. I built and tested the workflow in GIDE.

**70–75 sec — Close**  
Variance turns a month-end spreadsheet hunt into a fast, evidence-backed executive explanation.
